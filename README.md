
# LangGraph Customer Support Agent

## Description
A simple rule-based customer support agent
built using Python and LangGraph.

## Features
- Question classification
- Order support
- Refund support
- Payment support
- Return support
- Conditional routing
- Interactive command-line interface

## Technologies
- Python
- LangGraph
- TypedDict

## Installation

pip install -r requirements.txt

## Execution

python main.py
